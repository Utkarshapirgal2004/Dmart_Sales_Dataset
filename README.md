# Excel Lab Exercises — DMart Retail Dataset

## 📌 Overview

This repository contains seven Excel lab exercises completed as part of academic coursework using the DMart retail dataset. The exercises provide hands-on practice in Microsoft Excel and demonstrate the application of spreadsheet techniques to retail data.

## 🎯 Objectives

- Develop practical Excel skills through structured lab exercises.
- Work with retail data using spreadsheet tools.
- Practice data organization and analysis.
- Strengthen spreadsheet-based problem-solving skills.

## 🛠️ Tools & Technologies

- Microsoft Excel
- DMart Retail Dataset
- Spreadsheet-Based Data Analysis

## 📁 Repository Contents

- `DMart_Retail_dataset.xlsx` — Retail dataset used for the lab exercises.
- `LAB 1.xlsx` to `LAB 7.xlsx` — Seven Excel lab exercise files.

## 🚀 Key Takeaway

These lab exercises provide practical exposure to Microsoft Excel and build a foundation in spreadsheet-based data handling and analysis using retail data.
